# KEKE HOME v4.52

## Final release

KEKE HOME v4.52 is the final 4.x build.

### Highlights

- Modern PS4 dashboard UI
- Live CPU/APU and SoC temperature monitoring
- Fan duty monitoring
- Internal storage monitoring
- Installed application browser
- Application icons, Title IDs and versions
- Application deletion with confirmation
- Real-time joystick visualization
- Automatic joystick drift test
- Network information
- System information
- Settings
- Automatic system diagnostic
- Improved typography and readability

### Tested firmware

- PS4 9.00 — tested and working
- PS4 11.00 — tested and working

Other supported firmware versions are expected to work, but have not been fully tested.
